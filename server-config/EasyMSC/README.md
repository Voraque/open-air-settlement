# Cave-only creepers

These two files are the authoritative Easy Mob Spawn Control configuration for Open-Air Settlement. They assign creepers a rule requiring no access to the sky. Natural surface creepers are denied; natural cave creepers use their normal spawning rules.

Deploy both files to the server's `config/EasyMSC/` directory while it is stopped, then restart the server. The setting affects future spawns immediately; it does not remove creepers that already exist.
