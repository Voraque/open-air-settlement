# Cinematic Weather trial

User selected Cinematic Weather first; Windy and Immersive Weathering remain follow-ups, not installed here. Minecraft automation paused at user request, including backups and Carry On activation. DH remains stopped.

Official Fabric 1.21.1 release 1.0.0 verified by SHA-512 and installed locally. Its metadata is client-only with compatible loader/Fabric API requirements. Shared entry/config prepared but not yet published. No server restart needed for this mod.

Initial trial uses half particle density; Particle Rain keeps rain rendering. Extra fog, camera effects, player/item pushing, rolling stones, destruction, grass/shader wind disabled. Other defaults retained, including storms. The mod unconditionally invokes a Complementary ZIP shader patcher at client startup, even with shader wind disabled. Original local shaderpacks were copied to private cinematic-weather/before-client/shaderpacks before installation. No shader edits have been invoked by this installation process.
