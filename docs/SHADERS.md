# Optional shader setup

The recommended Windows shader is **Complementary Reimagined r5.8.1**. It is not required for multiplayer and does not belong on the server.

1. Download it from the official [Complementary Reimagined release page](https://modrinth.com/shader/complementary-reimagined/version/yCCduG44).
2. Leave the download as a `.zip`; do not extract it.
3. In Minecraft: Options → Video Settings → Shader Packs → Open Shader Pack Folder. Put the zip in that folder.
4. Select **ComplementaryReimagined r5.8.1** and start with the **Low** profile. Move to Medium only after the world is stable.

The shader ZIP is deliberately not copied into this repository. Its license allows inclusion through Modrinth or CurseForge systems but prohibits redistribution as a direct-file upload. The official download above is the safe route.

### Benji's Apple-silicon Mac

Treat shaders as experimental, not part of the shared baseline. Iris documents Apple-silicon Macs as unsupported because of Apple’s OpenGL drivers. Keep shaders off first; the game itself remains fully playable without them.
